### 📦 What is an Array?
An **Array** is a fundamental data structure used to store a collection of items. It is the most basic and widely used way to organize data in computer science. 

To be considered a traditional array, it usually follows two strict rules:
* **Contiguous Memory:** All items are stored right next to each other in the computer's physical memory. There are no gaps between them.
* **Homogeneous Data:** Every item inside the array must be of the exact same data type (e.g., a list of *only* integers, or *only* strings).
